development_eligibility:
mean_paired_score_difference >= -0.01
SR@0.90 decrease <= 1 episode out of 20

selection_rule:
1. among eligible candidates maximize mean paired own-trajectory boundary-D1 reduction
2. tie at six-decimal precision: maximize mean paired common-prefix D3 reduction
3. remaining tie: choose smaller window
4. remaining tie: choose lower polyorder

confirmatory_rule:
exactly one selected SG configuration is evaluated on formal confirmatory seeds
no alternative SG configuration is evaluated after confirmatory unblinding
no post-unblind retuning is permitted

isolation_rule:
BSOP disabled
Temporal Ensemble disabled
EMA disabled
AASF disabled
SMA disabled

metric_rule:
actual executed actions are used
Boundary D1 uses own-trajectory query boundaries
D1 D2 D3 use the prespecified paired common executed prefix
time-normalized C1 C2 C3 use control_dt=0.1 s
task performance is analyzed separately from smoothness

interpretation_rule:
SG uses only the action chunk already generated by the current policy query
it does not access future environment observations
it is therefore described as within-predicted-chunk Savitzky-Golay smoothing
it is not described as a strictly trailing causal filter
